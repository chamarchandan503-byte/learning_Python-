# 🧮 Python Calculator App

## 📌 Project Description
Python Calculator App is a beginner-friendly project that performs basic mathematical calculations. It allows users to add, subtract, multiply, and divide two numbers.

The project uses Python functions and separate modules to make the code easy to understand and maintain.

## ✨ Features
- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Decimal number support
- Error handling for invalid inputs
- Prevention of division by zero
- Menu-based interface
- Repeat calculations until the user exits

## 🛠️ Technologies Used
- Python 3
- Python Functions
- Modules and Imports
- Exception Handling
- Conditional Statements
- Loops

## 💻 Requirements
- Python 3 installed
- Visual Studio Code (recommended)

No external Python libraries are required.

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

On Windows, you can also use:

```powershell
py main.py
```

5. Select an operation from the menu.
6. Enter the two numbers.
7. View the result.
8. Select Exit when finished.

## 📋 Calculator Menu
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exit

## 🧪 Example

```text
Choose an option: 1
Enter first number: 10
Enter second number: 5
Result: 15.0
```
